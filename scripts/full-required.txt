# 패치로 못 넘기는 판을 적어 두는 자리 (2026-08-27)
#
# ★★**파일이 있는 것만으로는 아무 일도 안 일어난다.** 릴리즈 워크플로가 보는 것은
#   「직전 태그 이후 이 파일이 **바뀌었나**」다 — 내용을 고친 판에서만 `requires_full` 이
#   켜지고, 그 판은 패치 대신 **전체 꾸러미로만** 내려간다. 안 고친 판은 평소처럼 패치다.
# ★왜 따로 두나 — `backend/requirements.txt` 에 주석을 더해도 같은 효과지만, 그러면
#   **왜 전체로 보냈는지**가 안 남는다. 여기 적으면 그 줄이 그대로 기록이 된다.
# ★배포물이 아니다 (`scripts/` 는 꾸러미에 안 담긴다).
#
# 형식: <버전>  <까닭>

3.0.0  폴더 배치가 두 층으로 바뀜(app/) — 패치에는 python 이 안 담겨 옛 자리에 남는다
3.2.1  파이썬에 pip 을 되살림 — 패치에는 python 이 안 담겨, 패치로 받으면 플러그인 의존성 설치가 계속 실패한다
